Atenção às datas: “última cotação” significa o registro mais recente armazenado pelo projeto, não uma consulta de mercado em tempo real. Dólar comercial e PTAX podem ter datas de referência distintas. As taxas são indicativas, não necessariamente as praticadas em uma operação de câmbio.

Endpoints públicos deste projeto

O GitHub Pages publica arquivos JSON estáticos, atualizados pelo GitHub Actions. São endpoints para consumo dos aplicativos, não uma API de consultas dinâmicas.

APIs das fontes originais

Links diretos para os provedores externos. Os aplicativos podem consumir apenas os JSONs centralizados acima, sem compartilhar a chave da AwesomeAPI.

AwesomeAPI

Fonte utilizada na coleta programada das cotações comercial e PTAX.

Últimas cotações, comercial + PTAX https://economia.awesomeapi.com.br/json/last/USD-BRL,USD-BRLPTAX
Histórico comercial (30 registros) https://economia.awesomeapi.com.br/json/daily/USD-BRL/30
Histórico PTAX (30 registros) https://economia.awesomeapi.com.br/json/daily/USD-BRLPTAX/30
Documentação Documentação oficial da AwesomeAPI

Banco Central do Brasil

Fonte oficial da PTAX. Os endpoints SGS abaixo retornam o último fechamento disponível, separadamente para compra e venda.

Última PTAX de compra (SGS 10813) https://api.bcb.gov.br/dados/serie/bcdata.sgs.10813/dados/ultimos/1?formato=json
Última PTAX de venda (SGS 1) https://api.bcb.gov.br/dados/serie/bcdata.sgs.1/dados/ultimos/1?formato=json
API Olinda: PTAX por dia ou período Documentação oficial da API PTAX
