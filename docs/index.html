USD/BRL: cotações e dados públicos

Atenção às datas: o dólar comercial é a última amostra capturada pela AwesomeAPI; a PTAX é o fechamento diário publicado nas séries oficiais SGS do Banco Central. Em dias não úteis ou antes da divulgação do fechamento, a PTAX pode ser de um dia anterior. Nenhuma dessas cotações equivale à taxa negociada com um banco.

Opção 1: serviço centralizado (coleta diária às 18h)

Os aplicativos podem consultar diretamente os JSONs públicos do GitHub Pages. O GitHub Actions agenda a coleta às 18h, no horário de Fortaleza; a execução real pode sofrer atrasos. Não é uma cotação continuamente atualizada nem uma API dinâmica.

Consultas diretas às APIs de origem

Links diretos, independentes do agendamento das 18h. Na geração dos JSONs do projeto, a AwesomeAPI fornece apenas o dólar comercial e o Banco Central fornece a PTAX de fechamento e seu histórico.

Opção 2: AwesomeAPI (consulta direta)

A cotação comercial de mercado é utilizada pelo serviço centralizado. A AwesomeAPI também oferece PTAX para consulta direta, mas não é a fonte da PTAX publicada pelo projeto. Os links não revelam a chave secreta do GitHub.

Fonte utilizada pelo projeto para recuperar a PTAX de fechamento e seu histórico por meio das séries SGS 10813 (compra) e 1 (venda). O SGS informa apenas a data da taxa, sem horário intradiário.

Qual fonte escolher? Use os JSONs deste projeto para obter a amostra comercial diária e a PTAX oficial consolidada. Consulte a AwesomeAPI diretamente para acompanhar o mercado ou o BCB para conferir as séries diárias de fechamento. Para negociações reais, confirme a taxa efetiva com a instituição financeira. O acesso às APIs externas está sujeito às condições de cada provedor; não exponha a chave da AwesomeAPI em páginas públicas.
